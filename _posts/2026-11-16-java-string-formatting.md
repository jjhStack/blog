`System.out.printf()`와 `String.format()`은 **서식 문자열** 안의 `%` 자리에 값을 채워 넣는다.
둘은 같은 규칙(`java.util.Formatter`)을 쓰고, 결과를 출력하느냐 문자열로 돌려주느냐만 다르다.

```java
System.out.printf("%s는 %d살%n", "철수", 20);          // 바로 출력
String s = String.format("%s는 %d살", "철수", 20);     // 문자열로 받음
String t = "%s는 %d살".formatted("철수", 20);          // Java 15부터
```

이 글의 결과는 모두 JDK 21에서 직접 실행한 것이다. 칸 수가 보이도록 결과를 `[` `]`로 감쌌다.

# 서식 지정자 문법

```
%[인덱스$][플래그][너비][.정밀도]변환
```

|부분|예|뜻|
|---|---|---|
|인덱스|`2$`|몇 번째 인자를 쓸지 (생략하면 순서대로)|
|플래그|`-`, `0`, `+`, `,`|정렬, 채움, 부호 같은 모양|
|너비|`10`|**최소** 몇 칸을 차지할지|
|정밀도|`.2`|실수는 소수점 아래 자릿수, 문자열은 최대 글자 수|
|변환|`d`, `s`, `f`|값을 어떤 형태로 바꿀지 (필수)|

변환만 필수이고 나머지는 모두 생략할 수 있다. `%-15s`는 플래그 `-`, 너비 `15`, 변환 `s`다.

# 변환 문자

|변환|대상|예|결과|
|---|---|---|---|
|`d`|정수 (10진)|`%d`, 42|`[42]`|
|`f`|실수 (소수점)|`%f`, 3.14159|`[3.141590]`|
|`e`|실수 (지수)|`%e`, 12345.678|`[1.234568e+04]`|
|`s`|아무 값 (문자열로)|`%s`, "java"|`[java]`|
|`c`|문자|`%c`, 'A'|`[A]`|
|`b`|boolean|`%b`, true|`[true]`|
|`x` / `X`|정수 (16진)|`%x`, 255|`[ff]` / `[FF]`|
|`o`|정수 (8진)|`%o`, 8|`[10]`|
|`n`|줄바꿈|`%n`|운영체제에 맞는 줄바꿈|
|`%`|`%` 문자 자체|`%%`|`[%]`|

`%f`는 정밀도를 안 주면 소수점 아래 **6자리**가 기본이다.

# 너비와 정렬

너비만 주면 **오른쪽 정렬**이 기본이다.

|서식|값|결과|
|---|---|---|
|`%5d`|42|`[   42]`|
|`%-5d`|42|`[42   ]`|
|`%10s`|"java"|`[      java]`|
|`%-10s`|"java"|`[java      ]`|
|`%5s`|"python123"|`[python123]`|

마지막 줄처럼 값이 너비보다 길면 **잘리지 않는다.** 너비는 최소 너비다.
문자열을 자르고 싶으면 정밀도를 쓴다. `%.2s`에 `"java"`를 넣으면 `[ja]`다.

# 플래그

|플래그|뜻|예|결과|
|---|---|---|---|
|`-`|왼쪽 정렬|`%-5d`, 42|`[42   ]`|
|`0`|빈칸을 0으로 채움 (숫자만)|`%05d`, 42|`[00042]`|
|`+`|양수에도 부호 표시|`%+d`, 42|`[+42]`|
|`,`|천 단위 구분자|`%,d`, 1234567|`[1,234,567]`|
|공백|양수 앞에 공백 한 칸|`% d`, 42|`[ 42]`|
|`(`|음수를 괄호로|`%(d`, -42|`[(42)]`|

`0`은 너비와 같이 써야 의미가 있다. `%03d`에 `1234`를 넣으면 너비를 넘으니 그대로 `[1234]`다.

# 실수: 정밀도와 반올림

|서식|값|결과|
|---|---|---|
|`%.2f`|3.14159|`[3.14]`|
|`%8.2f`|3.14159|`[    3.14]`|
|`%08.2f`|-3.14159|`[-0003.14]`|
|`%.0f`|2.5|`[3]`|
|`%.0f`|3.5|`[4]`|

- `%8.2f`의 너비 8은 소수점과 소수 자리까지 포함한 **전체** 칸 수다.
- `0` 플래그를 쓰면 부호 뒤에 0이 채워진다.
- `%.0f`에서 2.5가 3이 된다. `printf`는 반올림(`HALF_UP`)을 한다. 은행가 반올림(2.5 → 2)이 아니다.

# 인자 순서 바꾸기

|서식|인자|결과|
|---|---|---|
|`%2$s %1$s`|"world", "hello"|`[hello world]`|
|`%s %<s`|"hi"|`[hi hi]`|

`n$`는 n번째 인자를 쓰고, `<`는 바로 앞 지정자가 쓴 인자를 다시 쓴다.

# 로케일

숫자 모양(소수점, 천 단위 구분자)은 로케일을 따른다. 기본 로케일이 소수점으로 쉼표를 쓰는 곳이면 결과가 달라진다.

```java
String.format("%.2f", 3.14159);                  // "3.14" (en_US)
String.format(Locale.GERMANY, "%.2f", 3.14159);  // "3,14"
```

채점 서버처럼 정해진 출력이 필요하면 `String.format(Locale.US, ...)`처럼 로케일을 직접 넘기는 게 안전하다. `Scanner`의 `nextDouble()`도 같은 문제가 있다.

# 자주 나는 예외

|코드|예외|이유|
|---|---|---|
|`printf("%d", 3.14)`|`IllegalFormatConversionException`|`d`는 정수만 받는다|
|`printf("%f", 3)`|`IllegalFormatConversionException`|`f`는 실수만 받는다. `int`는 자동으로 바뀌지 않는다|
|`printf("%d %d", 1)`|`MissingFormatArgumentException`|지정자보다 인자가 적다|

반대로 `%s`는 아무 값이나 받는다. `printf("%s", 3.14)`는 `3.14`를 출력한다. 값의 `toString()` 결과를 쓰기 때문이다.

인자가 지정자보다 **많으면** 예외 없이 남는 인자는 무시된다.

# 정리

- 서식 지정자는 `%[인덱스$][플래그][너비][.정밀도]변환`이고 변환만 필수다.
- `d` 정수, `f` 실수, `s` 문자열, `n` 줄바꿈, `%%`는 `%` 문자다.
- 너비만 주면 오른쪽 정렬이다. 왼쪽 정렬은 `-`, 0 채우기는 `0` 플래그를 쓴다.
- 너비는 최소 너비라서 긴 값은 잘리지 않는다. 문자열을 자르려면 `%.ns`를 쓴다.
- `%.nf`는 소수점 아래 n자리로 반올림한다. 너비는 소수점까지 포함한 전체 칸 수다.
- 변환과 값의 타입이 안 맞으면 `IllegalFormatConversionException`이 난다.
- 숫자 모양은 로케일을 따르므로 출력 형식이 정해져 있으면 `Locale.US`를 넘긴다.

# 영어로 설명하기

> A format specifier has the form `%[argument_index$][flags][width][.precision]conversion`, and only the conversion is required. For example, `%-15s` left-justifies a string in a field of 15 characters.

> The width is a minimum width, so longer values are never truncated. For floating-point numbers, the precision sets the number of digits after the decimal point, and the value is rounded half up.
