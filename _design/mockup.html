Spring Boot 첫 실행 시 DataSource 설정 에러

2024년 3월 24일읽는 데 2분
이런 에러가 났다면

Failed to configure a DataSource: 'url' attribute is not specified and no embedded datasource could be configured.

전체 로그 보기 
***************************
APPLICATION FAILED TO START
***************************

Reason: Failed to determine a suitable driver class

Action:
  If you want an embedded database (H2, HSQL or Derby), please put it on the classpath.
  If you have database settings to be loaded from a particular profile you may need to activate it.
1

원인

DB에 연결할 정보가 없거나 잘못되어 있습니다. Spring Boot 프로젝트를 처음 만들고 설정을 고치지 않은 채 바로 실행하면 이 에러가 납니다.

2

해결

application.properties에 DB 연결 정보를 적어 줍니다.

application.properties
spring.datasource.url=jdbc:mysql://localhost:3306/[스키마명]
spring.datasource.username=[접속 ID]
spring.datasource.password=[접속 비밀번호]
spring.datasource.driver-class-name=com.mysql.jdbc.Driver
3

결과

서버가 정상적으로 뜹니다. 화면에 Whitelabel Error Page가 보이는 건 아직 컨트롤러가 없어 404가 나는 것이라 정상입니다.
