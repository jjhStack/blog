Spring Boot 첫 실행 시 DataSource 설정 에러

2024년 3월 24일읽는 데 2분
이런 에러가 났다면

Failed to configure a DataSource: 'url' attribute is not specified and no embedded datasource could be configured.

문제

Spring Boot 프로젝트를 처음 실행하자마자 서버가 뜨지 않고 위 에러가 났다.

원인

DB에 연결할 정보가 없거나 잘못되어 있기 때문이다. 프로젝트를 만들고 설정을 고치지 않은 채 바로 실행하면 이렇게 된다.

해결

application.properties에 DB 연결 정보를 적어 준다.

properties
spring.datasource.url=jdbc:mysql://localhost:3306/[스키마명]
spring.datasource.username=[접속 ID]
spring.datasource.password=[접속 비밀번호]
spring.datasource.driver-class-name=com.mysql.jdbc.Driver

결과

서버가 정상적으로 뜬다. Whitelabel Error Page가 보이는 건 아직 컨트롤러가 없어서다.
